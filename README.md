# Employee Record System (SQLite3 & Python)

A lightweight, terminal-based **Employee Record Management System** built with **Python** and **SQLite3**. This application allows users to perform full CRUD (Create, Read, Update, Delete) operations on an employee database with safe data input handlings.

## 🚀 Features
- **Add Employee:** Create new employee profiles with structural data inputs.
- **View Database:** Display all records cleanly formatted inside a terminal table layout.
- **Search Engine:** Query explicit profiles directly using unique Employee IDs.
- **Update Profiles:** Modify historical records cleanly without disrupting core keys.
- **Secure Deletion:** Remove records safely via standard operational confirmation prompts (`y/n`).
- **Crash Management:** Fully wrapped in robust `try-except` blocks preventing runtime integer conversion crashes.

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Database:** SQLite3 (Built-in)
